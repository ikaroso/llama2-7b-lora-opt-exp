# BF16 原始基线补测

原始基线为已合并中文 LoRA 的 BF16 GGUF，无量化、无投机。2026-09-12 报告中的“基准”只表示 Q4 GPU 无投机对照，不是原始精度基线。

## 协议

- BF16 CPU 与 Q4 CPU：同一 CUDA 构建，但 ngl=0，关闭 KV 和额外算子卸载，FA off，8 线程，batch/ubatch=128。此配对衡量同运行条件下的量化效果。
- Q4 GPU：ngl=99、FA on，其余参数相同。与 BF16 CPU 的比较属于本机整体部署收益，同时改变精度与执行后端。
- BF16 权重约 13.48 GB，无法全放入本机 8 GB 显存。CPU 是明确、可复现的原始基线，不宣称是 BF16 最快的部分 GPU 卸载配置。
- 五个独立轮次，每轮 CPU 两组交替先后，再测 GPU；不并行测量。每组独立进程、独立预热。server 每轮三个与前轮报告相同的 CMRC2018 真实问题，每个输入 512、输出 256，单并发、无提示缓存、忽略 EOS。
- TTFT 为请求开始到首个非空文本事件，排除模型加载。吞吐按总 token/总时间汇总；decode 遵循当前 server 的 255 次后续解码计时口径。最终 token 数检查依赖服务端最终计数，返回文本一致不代表完整 token ID 一致。
- llama-bench 每组五个独立进程，各测 p512 与 tg256；CPU 参数的布尔选项显式传 1，server 对应开关不带值。
- batch/ubatch 调整不再列为主优化方案；之前原始结果保留，不删除历史证据。主线为 BF16 → Q4 → Q4 GPU → ngram / TinyLlama draft-simple。

## 与投机实验衔接

投机结果沿用 2026-09-12 已完成的五轮：Q4 GPU 对照 decode 45.53 token/s，ngram-simple 53.93，TinyLlama draft-simple（最多草拟 3 token）66.63；同轮配对增益分别约 18% 和 46%。本次没有重新测投机，因此不将这些旧结果与 2026-09-13 BF16 数据相除并声称同轮整体倍率。两天 Q4 GPU 的 TTFT 存在差异，以各自原始记录为准。

TinyLlama 草稿来自 TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF，固定 revision 52e7645ba7c309695bec7ac98f4f005b139cf465，Q4_K_M 文件；draft-simple 是项目固定版本 llama.cpp 的普通草稿模型验证路径，没有为当前 LoRA 另行训练草稿。此前已核验词表映射兼容，质量与普遍无损仍未证明。

## 结果

已完成三个配置的各五轮确认：45 条正式 server 请求，以及 15 个 bench 进程。PPL 与正式质量评测不属于此次基线性能补测，仍未完成。

### 收益与限制

- **同 CPU 条件下的量化收益（server 五轮配对）**：prefill 1.489 倍，decode 2.049 倍，TTFT 降低 32.75%，请求总耗时降低 44.97%。这些只适用于本次固定执行条件和真实问题负载。
- **BF16 CPU → Q4 全 GPU 的整体部署收益**：prefill 122.19 倍，decode 10.90 倍，TTFT 降低 98.13%，请求总耗时降低 93.29%。该比较同时改变权重精度、GPU 卸载和 FA，不能称为纯量化收益，更不能代表相对最快 BF16 部分卸载方案的收益。
- **bench 独立确认**：BF16 CPU 的 pp512/tg256 为 18.22±0.31 / 4.48±0.08 token/s；Q4 CPU 为 26.21±1.09 / 9.90±0.06；Q4 GPU 为 2136.39±53.62 / 50.70±1.49。CPU 量化同轮配对 pp 为 1.439 倍、tg 为 2.211 倍。bench 不提供 TTFT，不将其结果与 server 混算。
- server GPU 采样最高 79°C、整卡显存最高 6154 MiB；这不是 CPU 温度，也不是模型独占或瞬时精确峰值。CPU/GPU 时钟、系统后台负载未严格控制；五轮有趋势变化，不宣称实验室条件下的因果精确倍率。
- 数据集、模型和来源沿用 bench/optimization-inputs-20260912.json。所有本次原始文件哈希、逐轮统计、范围和配对比值保存在 bench/bf16-results-20260913.json；原始日志位于 results/bf16-confirm-server-20260913 与 results/bf16-confirm-bench-20260913。性能测量结束后生成哈希。

复核和重新生成汇总：`python scripts/report_bf16.py`。脚本检查每组五轮、每轮三条、512/256 计数、无提示缓存、bench 退出码和 p512/tg256 配置。
