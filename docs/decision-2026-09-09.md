## 落地顺序

1. 将完整基座与 tokenizer 下载至 models/base，固定版本 LoRA 下载至 models/lora，登记来源与哈希。
2. CPU 加载基座并合并 LoRA，保存 BF16 至 models/merged-bf16，再重新加载检查。
3. 转换 BF16 GGUF，验证生成。
4. 本地 CPU 使用 llama-quantize 生成 Q4_K_M，验证生成和任务质量。
5. 配置 CUDA，验证 Q4 全量 GPU 卸载，随后比较 n-gram 投机解码。
6. 独立 draft 模型及组合保留为后续实验，先核对词表与显存。

本地量化可以使用 CPU 和系统内存，无需将 BF16 权重先放入 GPU。建议主机内存 32GB、空闲磁盘至少 60GB；本机 RAM、磁盘余量及合并峰值尚未确认。

## 显存预算

GPU 为 RTX 4060 Laptop，8188 MiB；一次检查报告空闲 5313 MiB，为瞬时值。Q4_K_M 权重预计约 4.4GB（4.1GiB），2K 单并发 FP16 KV 约 1GiB，另需运行缓冲。因此当前占用下不能保证全量 GPU 推理；建议释放至约 6GiB 空闲，或降低上下文。

CUDA 全量卸载可用 gpu_layers=99，并从启动日志验证实际卸载及 KV 位置；32 层不一定包含输出层。模板仍默认 CPU。Q8_0 KV 可作后续显存实验，尚未接入配置接口。
